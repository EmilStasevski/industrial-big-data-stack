# Security policy

This is a personal portfolio project, not production software; only the `main` branch is maintained.

## Reporting a vulnerability

Please report vulnerabilities privately via **Security → Report a vulnerability** on this repository
(GitHub private vulnerability reporting), not in a public issue. I aim to reply within a week.

## Scope notes

- The data comes from the public SMARD API (Bundesnetzagentur); no personal data is processed.
- The RAG assistant runs locally via Ollama; no data leaves the machine.
- The Go API is read-only and meant to run on localhost or behind a reverse proxy.
